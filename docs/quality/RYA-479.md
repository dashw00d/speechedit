## Behavior

Normal-workspace edits now push automatically using revision compare-and-swap and the same missing-media upload command as the shared editor. Local save status, original media and Undo history remain local. Guest changes still require the explicit, undoable Bring shared edits command. When the guest changed first, host pushes wait with a plain-language message; the existing three-way pull merges separate edits or explains overlapping edits without replacing either draft. Undo of a host correction or of brought-in guest edits is shared too. Failed requests retain local work and show an unsynced state while retrying on the existing 3-second interval.

Each live host tab retains its own merge ancestor so another host tab cannot silently advance its baseline. The per-room lock serializes background pushes and the existing Share-sheet pull. A changed revision during upload is rejected by the server, never force-retried. Original media never leaves this device except through the existing preview/recording sharing rules.

Changed product files: `OwnerSharedEdits.tsx`, `ownerSharedEdits.ts`, `collaborationClient.ts`, new shared `sharedMediaUpload.ts`. Browser regression: `scripts/owner-workspace-sync-smoke.cjs`, adapted from RYA-471 scenario F.
