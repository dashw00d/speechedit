User path: edit a word, let a collaborator save another passage, click Undo. The local word returns to its previous text and the collaborator's edit stays. No extra controls or decisions.

## Change

`collaborationClient.ts` applies clean incoming merges through the editor store's new `applySharedProject` action. `store.ts` rebases past/future snapshots and any open history group against the incoming delta, using the existing stable-object merge. Incoming values take precedence when a peer supersedes a historical local value, so Undo cannot silently restore that old value. Local asset references remain available. Edit coalescing ends at the remote boundary. Opening a project and explicit conflict resolution retain their existing reset behavior.

`collaborationHistory.test.ts` covers repeated peer saves, Undo/Redo, an existing Redo branch, superseded edits, peer deletion, local asset references, and grouped edits. `scripts/qa351-coop-merge-regression.cjs` is copied byte-for-byte from Builder's fd53ccc harness.
