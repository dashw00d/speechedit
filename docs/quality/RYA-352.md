# RYA-352 — cut/re-record collision checkpoint

Astra implementation during scheduled RYA-360. Based on e9b6590 (deployment-approximate), isolated clone `/home/ryan/.paperclip/workspaces/speechedit/astra-rya352`, branch `astra/rya352-cut-rerecord`. No ServerChirp changes or real-user data. Product commit: 335dc97.

Two people can no longer silently combine a cut and a re-recording into audio that mutes the following sentence. Merge compares the actual source mapping beneath changed replacement clips. Timing collisions return a plain-language conflict and a coherent local snapshot, so draft recovery and Keep my conflicting edits cannot apply an unsafe hybrid. Cuts before the slot also conflict when they shift the passage; cuts after it, text edits, and timing-neutral splits remain mergeable. Choosing a version requires redoing the other timing edit; automatic retiming is deliberately outside this fix.
